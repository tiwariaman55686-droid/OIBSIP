# Landing Page — CloudSync

A modern, responsive landing page built with clean semantic HTML5 and modern CSS3 (Flexbox & CSS Grid).

## Features
- **Sticky Navigation Bar:** Fast access to sections.
- **Hero Header:** Headline, subheadline, and Call-To-Action (CTA) buttons.
- **Features Section:** Responsive grid highlighting core platform pillars.
- **About Section:** Narrative overview with feature checklist.
- **Testimonials Section:** Card layout with user reviews.
- **Footer:** Navigation and social links.
- **Mobile Responsive:** Adapts cleanly across mobile, tablet, and desktop views without breaking layout.

## Tech Stack
- HTML5
- CSS3 (Custom CSS, Flexbox, CSS Grid)
- Google Fonts (Inter)
