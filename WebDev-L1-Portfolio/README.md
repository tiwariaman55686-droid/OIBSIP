# Personal Portfolio Website

A clean, responsive personal portfolio website showcasing skills, projects, and contact channels.

## Features
- **Hero & Profile:** Personal introduction, role summary, and quick action buttons.
- **About Section:** Background narrative and academic focus.
- **Skills Grid:** Visual breakdown of front-end and core computer science tools.
- **Project Cards:** Card-based showcase of featured projects with GitHub repository links.
- **Contact Channels:** Quick access to Email, LinkedIn, and GitHub profiles.
- **Fully Responsive:** Fluid layout built with CSS Grid and Flexbox for mobile and desktop screens.

## Tech Stack
- HTML5
- CSS3 (Flexbox, CSS Grid)
- Google Fonts (Poppins)
