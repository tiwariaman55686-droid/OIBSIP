# Temperature Converter Website

An interactive, responsive browser-based web application that converts temperatures between Celsius, Fahrenheit, and Kelvin in real time with input validation.

## Features
- **Multi-Unit Support:** Converts seamlessly across Celsius (°C), Fahrenheit (°F), and Kelvin (K).
- **Simultaneous Output:** Displays calculations for all three units at once.
- **Edge-Case Validation:** Prevents invalid numerical inputs and checks against absolute zero (−273.15°C / 0 K).
- **Reset Utility:** One-click clear and reset button.
- **Keyboard Support:** Supports standard button clicks as well as pressing the Enter key to calculate.
- **Modern Responsive Design:** Card-based UI built with custom CSS.

## Tech Stack
- HTML5
- CSS3 (Custom CSS, CSS Grid, Flexbox)
- JavaScript (Vanilla JS, Event Listeners, DOM Manipulation)
- Google Fonts (Poppins)
